### 🚀 Featured Projects

#### 💼 [FinSim](https://github.com/sagnik5549/FinSim)
A full-stack financial strategy game. You play Head of Investments at a fictional fund, trading on a simulated Indian-style exchange against quarterly targets and risk limits while your decisions decide whether you're promoted or fired.
- Multi-factor market engine with hidden regimes, sector factors, branching multi-day event chains and 5-minute ticks
- Portfolio & risk engine (fees, market impact, drawdown, VaR, beta, concentration limits)
- ML behaviour classifier + adaptive "director" that tunes difficulty within fair, tested bounds
- **Stack:** Python · FastAPI · SQLAlchemy · PostgreSQL/SQLite · React · TypeScript · Tailwind · Docker

#### 📊 [Market Analysis 2000–Present](https://github.com/sagnik5549/Market_Analysis_2000_Present)
Analysis of 26+ years of financial market data to uncover trends, volatility patterns and the impact of major economic events.
- **Stack:** Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter

#### 🔐 [Elliptic Curve Cryptography in C](https://github.com/sagnik5549/Elliptic-Curve-Cryptography-ECC-in-C)
A modular ECC implementation built from scratch using GMP: finite field arithmetic, point addition/doubling, double-and-add scalar multiplication, key generation, ECDH key exchange, message encoding, encryption/decryption, and curve visualisation.
- **Stack:** C · GMP · Make · Python (plots)

#### 🧠 [KDS Hackathon 2026](https://github.com/sagnik5549/kds_hackathon_2026)
A Backstory Consistency Verification System built for the KDS Hackathon 2026.
- **Stack:** Python
